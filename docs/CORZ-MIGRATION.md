## Validation scope

The CI config smoke test covers defaults and config persistence. The graphical smoke test launches the actual Fabric client under Xvfb, renders the title-screen Anarchy banner, opens and renders the Vortex dashboard, then shuts down. It does **not** enter a world, connect to a server, or validate module behavior in-game. No public server is contacted.

Full migration remains incomplete. Authentication/license controls are not migration targets and will not be bypassed.
